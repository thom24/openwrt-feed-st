## openstlinux-6.6-openwrt-24.10.4-mpu-v25.06.11

Changes in this release:

- Based on OpenWrt v24.10.4.

- Add PCIe support (root complex mode) for the STM32MP257-EV1 board (demo
  profile).

- Add USB flash programming support for STM32MP2 based boards and update
  flashing procedure.

## openstlinux-6.6-openwrt-24.10.2-mpu-v25.06.11

Changes in this release:

- Based on OpenWrt v24.10.2.

- Based on the BSP components of ST's 6.1 BSP.

- Add support for the STM32MP235F-DK board and the STM32MP215F-DK board.

- Add remoteproc support STM32MP2 based boards (demo profiles).

- Add USB Type-C (dual-role) support for STM32MP2 based boards (demo profiles).

## openstlinux-6.6-openwrt-24.10.1-mpu-v24.11.06

- Based on OpenWrt v24.10.1.

- Based on the BSP components of ST's 6.0 BSP.

- Add support for STM32MP257F-DK board.

- Add a Starter Package (prebuilt images, SDK, ImageBuilder, package
  repositories).

## openstlinux-6.1-openwrt-master-mpu-v24.06.26

- Based on OpenWrt master branch (commit 93881ec190)

- Based on the BSP components of ST's 5.1 BSP.

- Add support for STM32MP257F-EV1 board.

## openstlinux-6.1-openwrt-master-mp1-v23.06.21

Initial release:

- Based on OpenWrt master branch (commit cffd3ad8d7).

- Based on the BSP components of ST's 5.0 BSP.

- STM32MP135F-DK and STM32MP235F-DK-DK2 support (Ethernet, Wifi, Watchdog, LED,
  Button, USB-Type A, RTC, RNG).

- Sysupgrade support.

- OpenWrt images flashing using STM32CubeProgrammer.
